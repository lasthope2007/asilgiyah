# اصیل‌گیاه | ASILGIYAH
فروشگاه فارسی محصولات گیاهی با Next.js 14، TypeScript، Tailwind CSS، PostgreSQL و Prisma.

## وضعیت فعلی
این پروژه در حال تبدیل شدن از نمونه‌ی نمایشی به محصول واقعی است. **فعلاً فروش واقعی مجاز/آماده نیست**:
- کاتالوگ seed شامل ۴۳ محصول آزمایشی با قیمت و موجودی نمونه است؛ قبل از فروش باید با کالاها، قیمت‌ها و موجودی واقعی جایگزین شود.
- ثبت سفارش اکنون از سبد خرید، اطلاعات گیرنده و موجودی سمت سرور استفاده می‌کند و ثبت سفارش/کاهش موجودی/ثبت رویداد انبار را در یک تراکنش دیتابیس انجام می‌دهد.
- پرداخت فعلی کاملاً Mock است. وضعیت پرداخت در دیتابیس صریحاً `isSimulated=true` ذخیره می‌شود و هیچ پولی دریافت نمی‌شود.
- هزینه ارسال در صورت نبود متغیر `SHIPPING_FLAT_TOMAN` به‌صورت آزمایشی صفر است؛ قبل از استفاده واقعی باید روش و تعرفه ارسال تعریف شود.
- پنل مدیریت، ورود مدیر، حساب مشتری، اتصال درگاه بانکی، لغو و بازپرداخت، قوانین ارسال و فرایند عملیاتی فروش هنوز نیازمند تکمیل و بررسی‌اند.

## راه‌اندازی محلی
نیازمندی‌ها: Node.js 20+، pnpm 9+ و Docker.

1. فایل `.env.example` را به `.env` کپی کنید.
2. مقدار `DATABASE_URL` را با دیتابیس محلی تنظیم کنید.
3. اجرا کنید:

```bash
pnpm install
docker compose up -d db
pnpm db:generate
pnpm db:migrate
pnpm db:seed
pnpm dev
```

4. سایت در `http://localhost:3000` اجرا می‌شود.

## متغیرهای محیطی
- `DATABASE_URL`: اتصال PostgreSQL.
- `SHIPPING_FLAT_TOMAN`: هزینه آزمایشی ثابت ارسال به تومان؛ در نسخه فعلی مقدار پیش‌فرض صفر است.
- هیچ کلید یا رمز واقعی را در GitHub قرار ندهید.

## تست و Build
```bash
pnpm test
pnpm build
```

Build روی Vercel برای کامیت‌های قبلی checkout موفق بوده است؛ پس از آخرین تغییرات، استقرار نهایی باید دوباره بررسی شود. اجرای تست‌ها و تست end-to-end واقعی نیازمند دیتابیس و محیط اجرا است.

## مراحل باقی‌مانده پیش از فروش
1. تهیه دیتابیس PostgreSQL پایدار، اجرای migrationهای نسخه‌بندی‌شده و پشتیبان‌گیری.
2. جایگزینی داده‌های دمو با اطلاعات تأییدشده کالا، قیمت، وزن، تصاویر، موجودی و شرایط نگهداری.
3. تکمیل احراز هویت و پنل مدیریت با کنترل دسترسی سمت سرور و حذف مسیرهای نمایشی.
4. انتخاب شرکت ارسال و تعرفه واقعی؛ سپس اتصال درگاه پرداخت معتبر با callback امضاشده و بررسی وضعیت پرداخت از سمت سرور.
5. افزودن سیاست لغو/بازپرداخت، انقضای سفارش‌های پرداخت‌نشده، ثبت رضایت/حریم خصوصی، محدودسازی درخواست‌ها، پایش و پشتیبان‌گیری.
6. اجرای تست امنیتی و آزمون خرید کامل قبل از باز کردن فروش عمومی.

**توجه:** اجرای seed قیمت‌ها و موجودی نمونه را درج/به‌روزرسانی می‌کند؛ برای داده‌های واقعی، seed را روی دیتابیس تولید اجرا نکنید.
