# ASILGIYAH — اصیل‌گیاه
**The Essence of Persian Nature.** فروشگاه نمونه فارسی و RTL با Next.js App Router، TypeScript، Tailwind، PostgreSQL و Prisma.

> این خروجی یک پایه‌ی قابل توسعه است، نه فروشگاه آماده‌ی فروش واقعی. قیمت و موجودی‌ها داده دمو هستند. پرداخت واقعی وجود ندارد.

## راه‌اندازی
1. Node.js 20+ و pnpm 9+ نصب کنید.
2. `.env.example` را به `.env` کپی کنید و `SESSION_SECRET` را به یک مقدار تصادفی قوی تغییر دهید.
3. اجرا: `pnpm install`، `docker compose up -d db`، `pnpm db:generate`، `pnpm db:migrate`، `pnpm db:seed`، `pnpm dev`.
4. آدرس `http://localhost:3000` را باز کنید.

## داده دمو
Seed شامل ۴۳ محصول در ۸ دسته است. قیمت‌ها تومان و موجودی‌ها صرفاً نمونه‌اند. حساب نمونه مدیر: `admin@asilgiyah.local` / `DemoAdmin!2026`؛ فقط برای توسعه و باید قبل از انتشار حذف یا تغییر داده شود.

## مسیرهای فعلی
`/`, `/shop`, `/product/[slug]`, `/cart`, `/checkout`, `/about`, `/contact`, `/faq`, `/shipping`, `/returns`, `/privacy`, `/terms`, `/blog`.

## نکات مهم تکمیل
- سبد خرید مبتنی بر session ناشناس است؛ صفحه checkout در این نسخه فرم نمایشی دارد و هنوز endpoint نهایی ثبت سفارش/پرداخت را به‌صورت کامل به رابط متصل نمی‌کند.
- مدل‌های Prisma برای کاربر، آدرس، سفارش، پرداخت Mock، کوپن، دیدگاه، wishlist، موجودی، مقاله، بنر و audit log تعریف شده‌اند؛ همه‌ی گردش‌کارهای مدیریتی و حساب کاربری هنوز کامل نیستند.
- قبل از استفاده واقعی باید rate limiting، CSRF، سیاست‌های امنیتی، CRUD کامل مدیریت، صفحه سفارش‌ها و wishlist، پرداخت واقعی با callback امضاشده و بررسی امنیتی مستقل اضافه شوند.
- تصویر قهرمان از Unsplash است؛ منبع و مجوز تصاویر را پیش از انتشار بررسی کنید.
- پروژه تازه ساخته شده چون به پوشه‌های محلی رایانه شما دسترسی مستقیم وجود نداشت؛ مخزن موجودی از دستگاه شما قابل بررسی نبود.
